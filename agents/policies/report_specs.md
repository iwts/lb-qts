# Report Specs

> 本文件只定义"报告该长什么样"与"质量底线"。**"该怎么分析"看 `trading_playbook.md`；"哪些历史教训必须遵守"看 `learned_rules.md`**。
> 报告不是给人打卡看的，是给未来的自己和 Execution Agent 下单用的。形式服务内容。

## 分级标准

| 评级 | 分数区间 |
|---|---|
| 强力做多 | 80-100 |
| 推荐做多 | 68-80 |
| 看多 | 58-68 |
| 中性 | 42-58 |
| 看空 | 32-42 |
| 推荐做空 | 20-32 |
| 强力做空 | 0-20 |

## 信息密度优先于行数（核心原则）

> **重要原则变更**：原本"最低行数"门槛容易诱导 LLM 用重复、同义改写、模板化填充凑字数。从现在起：
> **不设"最低行数"硬性门槛，改设"信息密度门槛"与"段落等级上限"。**

### 段落等级定义（见 `trading_playbook.md` §10）

- **A 级（决策级）**：包含数值证据 + 逻辑链 + 交易动作 / 明确结论。
- **B 级（解释级）**：包含数值证据 + 解读，但未直接转化为动作。
- **C 级（描述级）**：仅复述数据或泛泛描述。

### 质量门禁

- **C 级段落占比 > 30% → 自动 `degraded`**。
- 任何段落若是上一段的同义改写 → 视为 C 级。
- 报告中同一数值（例如当前价）被复述 >3 次 → `degraded`。
- 报告若包含"该股走势较强，建议关注"这类空话 → `degraded`。

### 长度约束（软性参考，不是硬性门槛）

- 基本面报告：参考 300–700 行；核心在密度，不在长度。
- 推理报告：参考 400–900 行；超过 1000 行但 C 级段落 <30% 仍可接受，反之一律降级。
- 执行报告：参考 150–400 行；过长反而可能稀释可执行性。

## 全局约束

1. **事实与推断必须分离**：事实要给原始数值 + 来源文件；推断要给逻辑链 + 置信度。
2. **每份报告必须包含"失效条件（invalidation）"**——不给失效条件的方向判断 = 无效判断。
3. **每份报告必须包含"风险优先级（高/中/低）"**。
4. **关键输入缺失时**必须显式写明：缺失项、降级影响、替代假设。
5. **禁止重复句、重复清单、同义改写凑字数**（见 `trading_playbook.md` §9 陷阱 8–9）。

## 基本面报告规范

- 文件：`deduction/<symbol>/fundamental_analysis_<yyyy_mm_dd>_<seq>.md`
- 强制结构（详见 `workers/fundamental_master_agent.md`）：
  1. 标的信息与数据新鲜度
  2. **五维分析**：质量 / 成长 / 估值 / 现金 / 催化剂
  3. 三维评分映射 + 权重 + 综合分
  4. Bull Case / Bear Case（各 ≥3 条证据）
  5. 情景概率分布（bull/base/bear 概率 + 预期回报）
  6. 综合结论 + 风险优先级 + **Technical × Fundamental 整合提示**
- 强制输出字段：
  - 综合基本面评分 `0-100`
  - 基本面评级（按分级标准）
  - `fundamental_direction`（bullish / neutral / bearish）
  - `risk_priority`（高/中/低）

## 推理报告规范（核心报告）

- 文件：`deduction/<symbol>/deduction_<yyyy_mm_dd>_<seq>.md`
- 强制结构（交易员六步决策链，详见 `workers/reasoning_agent.md`）：
  1. **Step 1 市场体制识别**（含三维框架 + 体制标签）
  2. **Step 2 多周期共振矩阵**（1w/1d/1h 三行完整 + 结论）
  3. **Step 3 双侧证据**：Long Thesis ≥3 条 + Short Thesis ≥3 条 + 对比定量
  4. **Step 4 交易机会类型选择**（6 类中的一种或"观望"，含不选项的理由）
  5. **Step 5 交易计划 ≥2 套**（每套 12 字段，见 `trading_playbook.md` §6.2）
  6. **Step 6 `learned_rules` 适用性 + 动态权重**
  7. **Step 7 最终方向、失效条件、执行优先级、监控清单**
- 强制约束：
  1. 必须同时评估 long 与 short。
  2. `best_rr < 1.5` 或多空差异 <10 分 → 强制输出 `neutral`。
  3. 必须"主计划 + 独立备选计划"，备选不能只是主计划的变体。
  4. 必须引用 `learned_rules` 编号；无命中时写"无命中规则 + 原因"。
  5. 每套计划必须通过 RR / 止损方向 / 止损距离 / 两档止盈 四项校验。

## 执行报告规范

- 文件：`report/<symbol>/report_<yyyy_mm_dd>_<seq>.md`
- 强制结构（详见 `workers/execution_agent.md`）：
  1. 最终结论（short-term / mid-long）
  2. **今日可执行清单**（if-then 格式，每行一个动作）
  3. **关键价位与触发器**（表格：上方 3 阻力 / 下方 3 支撑 + 触发动作）
  4. **仓位数学**（单笔 R、股数、占比、仓位系数）
  5. 风险控制（单日/组合/事件/心理）
  6. 规则触发摘要（引用 `learned_rules` 编号）
  7. 失效条件与应急动作
- 强制输出字段：
  - `direction`: long | short | neutral
  - `entry`, `stop`, `target_1`, `target_2`
  - `rr`, `position_size`, `time_horizon`
  - `stop_distance_atr`（止损距离 = x 倍日线 ATR）

## 复盘报告规范

- 文件：`deduction/<symbol>/review_<yyyy_mm_dd>_<seq>.md`
- 强制结构（详见 `workers/review_agent.md`）：
  1. **预测 vs 实际对照表**（历史方向、关键位、实际触发情况、实际 RR）
  2. 案例归因分类（A–F 六类）
  3. **思维漏洞识别**（≥1 条具体漏洞描述）
  4. 规则生命周期动作（新增/强化/降级/废弃，单案例不立规则）
  5. 外部观点交叉（若有 `challenges.md`）
  6. 复盘质量评分（0–100）

## YouTube 挑战报告规范

- 文件：`data/youtube_insights/challenges.md`
- 必含：挑战对象、现有策略、外部观点、可执行建议、置信度。
