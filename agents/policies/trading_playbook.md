# Trading Playbook（交易方法论核心）

> 本文是本 Agent 系统的"交易员大脑"。所有分析类 worker（strategy / reasoning / fundamental / execution / review）**必须**在开始分析前完整读取本文件，并在输出中遵循本文定义的思考路径。
>
> **位阶说明**：`learned_rules.md`（实战规则）> 本文件（通用方法论）> 报告格式规范。冲突时以 `learned_rules.md` 为准；本文件定义"默认怎么想"，`learned_rules.md` 定义"哪些例外不能犯"。
>
> **Token 预算纪律**：输出时至少 70% 的 token 必须用于"分析与决策"，而不是复述数据、填充模板。若发现自己在重复 `llm_context.md` 的原始数值却未加解释，立即停止并重写。

## 0. 交易哲学（先立场，后动作）

1. **交易员优先，不是报告员**：每一段输出必须能回答"这对下单决策有什么用？"。无法回答者删除。
2. **风险先于收益**：先确认最大可承受亏损（R），再反推入场与仓位，最后才算盈亏比；顺序不可颠倒。
3. **空白交易与错误交易同等有害**：为了"输出完整报告"而强行给方向，是本系统最常见的失败模式。证据不足的唯一正确答案是 **观望（neutral）**。
4. **概率与赔率分离**：高胜率 ≠ 高期望值。胜率 40%、RR 3 的交易远优于胜率 70%、RR 1 的交易。
5. **尊重市场结构，不信仰指标**：指标是结构的投影；当指标与价格结构矛盾时，以价格结构为准。
6. **不预测，要应对**：不写"价格将涨到 X"，写"若站上 X 且量能放大则做多，跌破 Y 则失效"。

## 1. 市场体制识别（所有分析的起点，必须先做这一步）

> **硬性要求**：任何交易方向判断前，必须先明确当前市场体制。体制决定了"哪些信号可信、哪些信号失效"。若跳过此步直接给方向，结论视为不可信，必须返回 `degraded`。

### 1.1 三维识别框架

| 维度 | 数据源（来自 `signals_summary.json`） | 判断方法 |
| --- | --- | --- |
| **趋势强度** | `adx` | <20 无趋势；20–25 弱/过渡；25–40 强趋势；>40 趋势衰竭预警 |
| **方向** | `ma_alignment`、`di_plus` vs `di_minus`、价格 vs SMA20/60 | 多头排列 + +DI 领先 = 上行；空头排列 + -DI 领先 = 下行；mixed = 方向未定 |
| **波动率** | `atr_14` 占股价比、`bb_width`、近 20 日 ATR 比 | <1.5% 低波；1.5–3% 正常；>3% 高波；ATR 比 <0.8 收缩，>1.2 扩张 |

### 1.2 六种体制与对应打法

| 体制 | 识别条件 | 可做 | 不可做 | 仓位倾向 |
| --- | --- | --- | --- | --- |
| **强势趋势市（顺）** | ADX>25 且多头排列 | 回踩做多、突破跟随 | 逆势抄底做空 | 常规 100% |
| **强势趋势市（逆）** | ADX>25 且空头排列 | 反弹做空、破位跟随 | 抄底做多（除非有明确反转结构） | 常规 100% |
| **弱趋势/过渡** | ADX 20–25，MA 交织 | 轻仓试探、等结构明朗 | 重仓单边 | 常规 50% |
| **震荡市** | ADX<20，BB 不扩张 | 区间高抛低吸 | 突破追单（假突破概率高） | 常规 50–70% |
| **波动率收缩** | BB 宽度近 20 日最低 20% 分位 | 等待突破方向 | 提前押方向 | 先观望 |
| **波动率扩散/事件** | ATR% 跳升、单日 >2×ATR 振幅 | 等待第二根 K 线确认后再决策 | 第一根 K 线内进场 | 常规 30% |

### 1.3 体制切换的早期信号

- 趋势→震荡：ADX 从 >25 回落至 <20 且 MA 转为交织；MACD 柱缩窄、OBV 走平。
- 震荡→趋势：BB 宽度扩张 + 放量突破区间边界 + ADX 上穿 20。
- 趋势衰竭：ADX >40 后回落、价格 vs RSI 背离、量价背离。

## 2. 多周期 Top-Down 框架

> **核心纪律**：高周期定方向，中周期定结构，低周期定触发。**逆高周期交易必须明确写出"为什么敢逆"**，否则视为错误。

### 2.1 分工

| 周期 | 角色 | 关注点 |
| --- | --- | --- |
| 1w（周线） | **Why**：战略方向 | 长期趋势、结构位、季度级别支撑阻力、MACD 与 ADX 长期状态 |
| 1d（日线） | **What**：战术结构 | 当前摆动结构（HH/HL or LH/LL）、均线排列、关键日线支撑阻力、日线体制 |
| 1h（小时线） | **When**：执行触发 | 入场触发、即时动量、微观结构、精确止损位 |

### 2.2 共振决策矩阵（强制）

> 以 `llm_context.md` 中"多周期共振"表为输入。

| 1w 趋势 | 1d 趋势 | 1h 趋势 | 结论 | 典型动作 |
| --- | --- | --- | --- | --- |
| 多 | 多 | 多 | 三周期共振做多 | 重仓，追突破或回踩 |
| 多 | 多 | 空 | 日线趋势 + 1h 回调 | 等 1h 企稳做多 |
| 多 | 空 | 空 | 周线主升中段回调 | 等日线结构修复再入场，不追空 |
| 空 | 空 | 空 | 三周期共振做空 | 反弹做空 |
| 空 | 空 | 多 | 空头市场 1h 反弹 | 不追多；等 1h 衰竭做空 |
| 空 | 多 | 多 | 熊市反弹 | 只做反弹，不当反转，仓位 ≤50% |
| 多 | 空 | 多 | 牛市回调中的 1h 反抽 | 不追多；等日线修复 |
| 混合/分歧 | — | — | 体制不清 | **观望**是默认答案 |

### 2.3 冲突解决原则

1. 高周期优先级高于低周期。
2. 价格结构优先级高于动量指标；动量指标高于震荡指标。
3. 当 1h 与 1d 冲突且 ADX 日线 >25：尊重日线（见 `learned_rules` 1.7）。
4. 当 1d 与 1w 冲突且周线空头排列 + death_cross：评分上限锁在看空区（见 `learned_rules` 1.3）。

## 3. 价格结构（Price Action）—— 交易员的母语

> 所有指标本质上都是价格结构的滞后投影。先读结构，再读指标。

### 3.1 摆动结构

- **多头结构**：连续 Higher High + Higher Low（HH/HL）。关键 HL 是多头防线。
- **空头结构**：连续 Lower High + Lower Low（LH/LL）。关键 LH 是空头防线。
- **结构破坏**：
  - 多转空：最近一个重要 HL 被有效跌破（收盘跌破 + 1×ATR 以上的幅度或放量跌破）。
  - 空转多：最近一个重要 LH 被有效突破。
- **结构盘整**：HH/HL 或 LH/LL 链条中断但未被破坏，等待新结构点。

### 3.2 关键价位的质量排序（由强到弱）

1. **高周期 + 多重属性重合**：如日线前高 = 周线 SMA60 = 布林下轨，重合价位 = 高质量。
2. **多次测试有效的结构位**：被触及 ≥3 次未破的支撑/阻力。
3. **成交密集区（Volume Profile 替代：近 60 日密集收盘区间）**。
4. **心理整数位 / 前期缺口**。
5. **单一均线价位**：单独使用可信度低，应与结构位结合。

### 3.3 支撑/阻力的"有效性"判定

- **有效突破**：收盘突破 + 突破幅度 ≥ 0.5× 日线 ATR + 成交量 ≥ 近 20 日均量 1.2× + 次日不跌回。
- **假突破**：日内突破但收盘回撤进入区间内（极危险，是反向入场的优质信号）。
- **有效跌破**：对称定义。

## 4. 七大分析维度（每个维度必须回答"怎么用"）

### 4.1 趋势（Trend）

- **核心问题**：现在是否有趋势？方向？强度？
- **数据**：`ma_alignment`、`adx`、`di_plus/minus`、价格距 SMA20/60 距离。
- **使用规则**：
  - ADX<20 + MA 交织 = 无趋势 → 不做趋势跟随，只做区间。
  - ADX 20–25 = 过渡 → 轻仓试探，等确认。
  - ADX>25 + 多头排列 → 主方向做多；任何做空信号视为"反弹做空"，仓位减半。
  - ADX>40 → 警惕趋势衰竭，止盈优先于加仓。
- **常见误用**：在 ADX<20 的震荡市把"均线交叉"当趋势信号 → 系统性亏损源。

### 4.2 动量（Momentum）

- **核心问题**：趋势还有没有动力？是否加速/减速/背离？
- **数据**：`macd_cross`、`macd_hist_value`、`macd_trend`、`rsi_12`、`kdj_j`、`divergence`。
- **使用规则**：
  - MACD 金叉/死叉**必须**结合 ADX 使用。ADX<20 时金叉死叉 60%+ 为假信号。
  - RSI：趋势市中 RSI>70 是强势（`learned_rules` 1.7 的姊妹原则），震荡市中 RSI>70 才是卖点。
  - KDJ J 值极端值（>100 或 <0）在强趋势中不应视为反转信号。
  - **背离是最重要的动量信号**：`divergence != "none"` 时必须在报告中专门讨论。
- **分层置信度**：多周期动量共振 > 日线级动量 > 1h 级动量。

### 4.3 波动率（Volatility）

- **核心问题**：当前波动状态决定止损空间与仓位。
- **数据**：`atr_14`、ATR 占股价百分比、`bb_width`、`bb_pctb`、近 20 日 ATR 比。
- **使用规则**：
  - **止损距离 ≥ 1.5× 日线 ATR**（`learned_rules` 4.1 强制）。
  - ATR% >3% 属高波动 → 仓位自动下调至常规 50%。
  - BB 收缩（width 近 20 日最低 20% 分位）= 即将突破 → 准备突破计划，不提前押方向。
  - BB%B >0.95 或 <0.05 在震荡市是反转信号，在趋势市是延续信号——**必须结合体制判断**。

### 4.4 量能（Volume）

- **核心问题**：价格变动是否有资金支持？
- **数据**：`volume_ratio`、`volume_status`、`obv_trend`、上涨/下跌日的量价关系。
- **使用规则**：
  - **放量突破** = 真突破优先证据（量比 >1.5）。
  - **缩量上涨** = 量价背离，持续性存疑，报告必须明确标注（除 `learned_rules` 3.0 防御性标的例外）。
  - **缩量下跌** = 恐慌未释放或空头弹药不足，不能仅凭此做多。
  - **放量下跌** = 强烈空头信号，应显著下调评分。
  - OBV 方向 vs 价格方向分歧 = 资金面背离，权重高于单根 K 线信号。

### 4.5 资金流（Capital Flow）—— A 股/港股优先

- **核心问题**：主力资金和大额资金在做什么？
- **数据**：`capital_flow.csv`、`capital_distribution.csv`、`orderflow_snapshot.json`。
- **使用规则**：
  - **大单净流入 + 大额资金净流出**（即散户/游资涌入、机构出货）= 典型派发，短期评分上限 55（见 `learned_rules` 2.1）。
  - **连续多日大单净流入** = 主力建仓信号。
  - **缩量 + 大单净流入** = 静默吸筹。
  - **放量 + 大额净流出** = 派发，强空头信号。
  - 资金流方向与价格背离超过 3 日：权重优先于短期 K 线形态。

### 4.6 支撑阻力与关键价位

- **核心问题**：当前价距最近关键位多远？风险回报如何？
- **数据**：`llm_context.md` 的 S/R 表（布林、SMA、近期高低、枢轴）。
- **使用规则**：
  - **不在关键位正中间入场**。应在关键位下沿（做多）或上沿（做空）布局。
  - 入场价距离下方最近强支撑 < 1× ATR = 风险回报不佳，考虑等待回踩。
  - 上方阻力距离 < 1× ATR 时，目标 1 应设在该阻力，不强求更大目标。
  - **多重重合价位** > **单一均线价位**。

### 4.7 多周期共振（Resonance）

- 已在第 2 节定义矩阵。实际使用时需在报告中显式填写三周期的趋势/动量/体制表，并明确"本次交易是顺共振还是逆共振"。
- 逆共振交易的仓位上限 = 常规 50%，且必须有明确反转结构触发（不是仅靠指标）。

## 5. 交易机会分类（六类 + 一类特殊：不交易）

### 5.1 突破做多（Breakout Long）

- **适用**：趋势市或波动率收缩后扩张。
- **触发**：收盘 > 关键阻力 + 量比 ≥1.5 + ADX 上行。
- **失效**：次日跌回区间 或 收盘回到突破价下方 0.5× ATR 以内。
- **止损**：突破价下方 1× ATR 或最近 HL 下方。
- **典型陷阱**：震荡市中的假突破。若 ADX<20，突破策略胜率低于 40%。

### 5.2 回踩做多（Pullback Long）—— 趋势市的最优做法

- **适用**：日线/周线多头趋势 + 1h 回调至关键支撑。
- **触发**：价格触及 SMA20/60 或前期 HL 附近 + 出现反转 K 线（锤子、吞没）或 1h MACD 底背离。
- **失效**：跌破 HL 或支撑带 1× ATR 以上。
- **止损**：支撑位下方 1–1.5× ATR。
- **优势**：RR 通常 2.5+，且止损结构清晰。

### 5.3 反弹做空（Short on Rally）

- **适用**：日线/周线空头趋势 + 1h 反弹至关键阻力。
- **触发**：反弹至 SMA20/60 或前期 LH 附近 + 出现反转 K 线 + 量能萎缩。
- **失效**：突破 LH 或阻力带。
- **注意**：**基本面强劲标的禁止做空**（`learned_rules` 1.4 强制）。

### 5.4 反转交易（Reversal）—— 最难，默认不做

- **适用**：明确的趋势衰竭信号叠加。
- **触发要求**（必须全部满足，否则不做）：
  1. 日线级背离（价格新高但 MACD/RSI 未新高）；
  2. 结构破坏（突破/跌破前期重要 HL/LH）；
  3. 量能确认（反转当日放量 ≥2× 均量）；
  4. 高周期（1w）也出现至少一项一致信号。
- **仓位**：不超过常规 50%。
- **失效**：返回原趋势方向突破。

### 5.5 区间交易（Range）

- **适用**：ADX<20 + BB 宽度稳定。
- **动作**：区间下沿做多、区间上沿做空；止损区间外 1× ATR。
- **退出条件**：ADX 上穿 20 且出现放量突破 → 立即平仓并转突破思路。

### 5.6 观望 / 不交易（Stand Aside）—— 本系统的默认答案

**必须选择不交易的情况**（任一命中都应输出 `neutral`）：

1. 三周期趋势分歧 + ADX<25；
2. `best_rr` 计算后 <1.5；
3. 关键数据缺失（见各 worker 的缺失数据处理）；
4. 波动率异常扩张（如单日 >3× ATR）当日；
5. 重大事件（财报、重要宏观数据）48 小时窗口内，且无事件驱动策略；
6. 多空证据势均力敌，差异 <10 分；
7. 当前价正处于关键价位正中间（上下 0.5× ATR 内既无清晰支撑也无清晰阻力）。

> **纪律**："不交易"不等于"没分析"。观望结论也必须包含：体制判断、为什么不交易、需要看到什么才会改变观点、失效条件。

## 6. 交易计划构建：风险优先七步法

> 每套交易计划的构造顺序**必须**按此顺序思考，不得跳步。

```
Step 1. 体制：当前市场体制是什么？（第 1 节）
Step 2. 方向：多/空/观望？基于多周期共振矩阵（第 2.2 节）。
Step 3. 入场类型：突破 / 回踩 / 反弹 / 反转 / 区间？（第 5 节）
Step 4. 触发条件：什么价格 + 什么确认（量/动量/结构）？
Step 5. 失效条件（Invalidation）：什么价或什么信号出现 = 方案作废？
Step 6. 风险预算：
        - 定义单笔 R（建议账户 0.5%–1%）；
        - 入场—止损距离 ≥ 1.5× ATR；
        - 仓位 = R / (入场价 − 止损价)。
Step 7. 目标与出场：
        - 目标 1 = 最近强阻力/支撑（保守止盈）；
        - 目标 2 = 趋势止盈（持有至趋势反转信号）；
        - RR 必须 ≥1.5，否则回到 Step 3 重选入场类型或放弃。
```

### 6.1 每次必须输出 ≥2 套计划

- **主计划**：最优 RR、最高置信度的方案。
- **备选计划**：当主计划触发失效时仍可执行的"Plan B"（通常是相反方向的反转计划或更保守的观望计划）。
- 备选计划不是"凑数"，其触发条件必须独立且清晰。

### 6.2 计划的最小要素清单

| 字段 | 要求 |
| --- | --- |
| direction | long / short / neutral |
| entry_type | breakout / pullback / rally_short / reversal / range |
| entry_price | 具体价位或价带 |
| trigger_conditions | 可量化确认信号（价格 + 量能 + 动量） |
| stop_loss | 价位 + "x 倍 ATR" 标注 |
| target_1 | 保守止盈 |
| target_2 | 趋势止盈 |
| rr | 按 target_1 计算 |
| position_size | 按风险公式计算（%账户或 share 数） |
| invalidation | 失效信号（文字描述） |
| time_horizon | 预期持仓时长（intraday / swing 2–5d / position >5d） |

## 7. 风险、止损与仓位数学

### 7.1 止损原则

1. **结构止损优先于指标止损**：若关键结构位（HL/LH、支撑带）在合理距离，优先用结构位。
2. **ATR 作为距离校验**：结构止损与入场距离 < 1× ATR → 太紧，易扫损；> 3× ATR → 太远，RR 不经济。理想 1.5–2.5× ATR。
3. **做多止损必须低于入场**（`learned_rules` 4.3）；做空止损必须高于入场。
4. 止损一经设定，**只能向有利方向移动（跟踪止损）**，禁止向不利方向扩大。

### 7.2 仓位公式

```
单笔风险 R = 账户资金 × risk_per_trade_pct (建议 0.5%–1%)
股数 = floor( R / |入场价 − 止损价| )
仓位占账户比例 = 股数 × 入场价 / 账户资金
```

### 7.3 仓位调整矩阵

| 情形 | 仓位系数 |
| --- | --- |
| 顺共振 + 高基本面评分 + ADX>25 | 1.0 |
| 弱趋势/过渡体制 | 0.5 |
| 逆共振交易（有明确反转结构） | 0.5 |
| 高波动（ATR%>3%） | 0.5（`learned_rules` 4.1） |
| 事件风险窗口内 | 0.3 或跳过 |
| 观望 | 0 |

### 7.4 两档止盈的必要性

- 只给单一保守目标会系统性压低 RR，放弃趋势市最大收益（`learned_rules` 4.2 强制）。
- 目标 1 完成后：将止损移至保本，剩余仓位按趋势止盈运行。

## 8. 基本面 × 技术面整合

### 8.1 四象限决策

|  | 技术面看多 | 技术面看空 |
| --- | --- | --- |
| **基本面强（≥75）** | 主力做多区，趋势回踩重仓 | 等回踩做多；**禁止**推荐做空（`learned_rules` 1.4） |
| **基本面弱（<50）** | 只做短线反弹，仓位 ≤50% | 主力做空区，反弹做空 |

### 8.2 基本面的"一票否决"

- 近一季营收/利润**同比 + 环比双降** + 自由现金流为负 → 技术面再好，评分上限 65（禁止"强力做多"）。
- 重大事件型利空（监管、诉讼、核心产品失败）→ 技术面信号全部降权；可突破 `learned_rules` 1.4 进入看空（本身就是规则的"例外条款"）。
- 基本面评分 72–74 的灰区：禁止引用 `learned_rules` 1.4，但也不强行给"推荐做空"（`learned_rules` 0.1）。

### 8.3 催化剂的时间窗口

- 财报窗口（前 5 日、后 2 日）：趋势交易降仓 50% 或转事件驱动策略。
- 行业政策/宏观数据窗口：提前识别，报告中必须列出。

## 9. 常见思维陷阱（报告自检清单）

写完报告前必须逐条自检：

1. 我是否只找了支持我方向的证据？（确认偏差）
2. 我的止损是否因为"这样 RR 才够 1.5"而被人为拉紧？（倒推 RR）
3. 我是否在 ADX<20 震荡市里用了金叉/死叉作为核心依据？
4. 我是否在基本面强势的标的上给了技术面做空？（违反 1.4）
5. 我的"看多"是否只来自 1h 信号而忽略了日线空头排列？（违反 1.7）
6. 我的"反转"结论是否只有一项条件？（需至少四项，见第 5.4 节）
7. 我是否在证据不足时强行给方向而不是观望？
8. 我的两套计划是否只是"做多 + 做多更激进"？（不符合独立备选原则）
9. 我有没有用重复句、同义改写凑字数？
10. 我引用的规则编号是否真的对应基本面门槛？（`learned_rules` 0.1）

**任一条回答"是"，报告必须重写或显式标注 `degraded`。**

## 10. 输出质量标准（与形式要求解耦）

> 本节取代"最低行数"心智模型。行数是结果不是目标。

### 10.1 信息密度定义

**合格段落 = 每 3–5 句中至少有 1 个具体数值 + 1 个决策建议/结论。**

段落质量分级：

- **A（决策级）**：包含数值证据 + 逻辑链 + 交易动作建议。
- **B（解释级）**：包含数值证据 + 解读，但未直接转化为动作。
- **C（描述级）**：仅复述数据或泛泛而谈。

**报告中 C 级段落占比 >30% → 自动标记 `degraded`。**

### 10.2 必须避免的写法

- "该股走势较强，建议关注" —— C 级，删除。
- "MACD 金叉，动量向好" —— 没引数值、没结合体制，C 级。
- "回踩 10.23 做多，止损 10.20，目标 10.35" —— A 级（数值 + 动作 + 可执行）。

### 10.3 Token 预算参考

| 内容类别 | 预算占比 |
| --- | --- |
| 数据复述（必要最小） | ≤10% |
| 体制识别 + 多周期共振分析 | 20% |
| 长/短两侧证据梳理 | 25% |
| 交易计划构造 + 风险数学 | 30% |
| 失效条件 + 风险自检 + 规则引用 | 15% |

**若发现自己在"数据复述"上超过预算，立即压缩——90% 以上的数据已经在 `llm_context.md`，不需要搬运。**

## 11. 与 `learned_rules.md` 的协作

- 本 playbook 是"通用方法论"；`learned_rules.md` 是"历史教训的例外条款"。
- 遵循优先级：`learned_rules.md` 强制规则 > 本 playbook 默认方法 > 报告格式规范。
- 当任一决策步骤触发 `learned_rules` 的某条规则（例如 1.4 / 1.6 / 4.1 / 4.3），**必须在报告中显式引用规则编号并说明影响**。
- 若本 playbook 方法在新案例中被证明系统性失效，应通过 Review Agent 将更新后的规则沉淀回 `learned_rules.md`，而不是修改本文件。

## 12. 分析流程最终摘要（可打印贴墙版）

```
1. 读 common_rules → runtime_contract → trading_playbook → learned_rules → report_specs
2. 体制识别：趋势 / 震荡 / 收缩 / 扩散？ADX、ATR%、MA 排列。
3. 多周期共振：1w → 1d → 1h，填共振矩阵。
4. 七维扫描：趋势、动量、波动、量能、资金流、S/R、共振。
5. 基本面整合：四象限定位，一票否决检查。
6. 识别交易机会类型：突破/回踩/反弹/反转/区间/观望。
7. 构造 ≥2 套计划：七步法，风险优先。
8. 自检 10 陷阱清单 + learned_rules 适用性。
9. 确定方向（含"观望"）、失效条件、优先级。
10. 输出：事实与推断分离、每段都要回答"对下单有什么用"。
```
